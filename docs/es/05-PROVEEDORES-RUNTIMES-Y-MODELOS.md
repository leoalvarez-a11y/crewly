# Proveedores, runtimes y modelos
## Que es
La configuracion de Claude Code, Codex CLI y catalogo de modelos.
## Para que sirve
Selecciona capacidad y proveedor por agente.
## Requisitos
CLI nativo, autenticacion real y PATH visible al PTY.
## Como abrirlo
Ve a **Configuracion > Proveedores y costos**.
## Configuracion paso a paso
Instala oficialmente, inicia sesion, prueba un fixture y asigna modelo.
## Ejemplo practico
Codex automatico con `strong_coding` elige un modelo compatible.
## Como comprobar que funciona
Version, autenticacion y tarea real aparecen correctas.
## Errores frecuentes
PATH distinto entre shell interactivo y servicio.
## Limites y riesgos
Modelos y tarifas cambian; no inventes disponibilidad.
## Acciones relacionadas
Equipos, Agentes, Costos y Terminales.

# Wiki y base de conocimiento
## Que es
El repositorio nativo de conocimiento curado.
## Para que sirve
Conserva procedimientos y resultados reutilizables.
## Requisitos
Vault accesible y permisos de escritura.
## Como abrirlo
Selecciona **Wiki**.
## Configuracion paso a paso
Elige vault, crea pagina, enlaza fuentes y guarda.
## Ejemplo practico
Publica el resultado validado de una reparacion.
## Como comprobar que funciona
La pagina reaparece tras reiniciar.
## Errores frecuentes
Confundir Wiki con salida temporal de chat.
## Limites y riesgos
No publiques credenciales ni conocimiento sin validar.
## Acciones relacionadas
Memoria, Ayuda, Skills y Proyectos.

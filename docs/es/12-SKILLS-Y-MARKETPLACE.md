# Skills y marketplace
## Que es
Capacidades instalables y catalogadas.
## Para que sirve
Extiende acciones de agentes sin cambiar su runtime.
## Requisitos
Permisos, dependencias y politica de seguridad compatibles.
## Como abrirlo
Selecciona **Marketplace** o **Configuracion > Skills**.
## Configuracion paso a paso
Revisa origen, instala, configura variables fuera de Git y prueba.
## Ejemplo practico
Habilita una skill de reporte para Documentation.
## Como comprobar que funciona
La skill aparece y su prueba controlada termina correctamente.
## Errores frecuentes
Instalar contenido premium en el repositorio OSS.
## Limites y riesgos
Una skill puede ejecutar herramientas con permisos del agente.
## Acciones relacionadas
Agentes, Seguridad, Integraciones y Logs.

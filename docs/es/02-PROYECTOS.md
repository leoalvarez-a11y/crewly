# Proyectos
## Que es
El registro de repositorios y objetivos.
## Para que sirve
Delimita el checkout donde trabaja un equipo.
## Requisitos
Ruta Git accesible por el usuario de Crewly.
## Como abrirlo
Selecciona **Proyectos**.
## Configuracion paso a paso
Crea el proyecto, indica nombre y ruta, valida la rama y guarda.
## Ejemplo practico
Registra `/home/usuario/app` sin usar `/mnt/c` para ejecucion WSL.
## Como comprobar que funciona
La ficha muestra ruta, rama y tareas vinculadas.
## Errores frecuentes
Ruta inexistente o permisos insuficientes.
## Limites y riesgos
No cambies de rama ni checkout fuera del alcance autorizado.
## Acciones relacionadas
Equipos, Solicitudes y Elementos de trabajo.

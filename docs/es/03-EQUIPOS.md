# Equipos
## Que es
Una agrupacion persistente de agentes y politicas.
## Para que sirve
Coordina liderazgo, ejecucion, QA y documentacion.
## Requisitos
Proyecto y runtimes disponibles.
## Como abrirlo
Selecciona **Equipos**.
## Configuracion paso a paso
Crea equipo, agrega miembros, asigna roles, runtimes, modelos y presupuesto.
## Ejemplo practico
Usa Claude como Leader y QA, Codex como Developer y Documentation.
## Como comprobar que funciona
Cada miembro conserva proveedor, modelo y rol tras reiniciar.
## Errores frecuentes
Confundir runtime predeterminado con configuracion por agente.
## Limites y riesgos
Mas miembros aumentan consumo concurrente.
## Acciones relacionadas
Agentes, Proveedores, Presupuestos y QA.

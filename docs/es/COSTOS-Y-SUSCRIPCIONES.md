# Costos y suscripciones

Crewly OSS no tiene costo de licencia. Crewly Pro es opcional y distinto del repositorio abierto. El costo de inferencia pertenece al proveedor y puede cambiar.

Claude Pro y Max son suscripciones de usuario; Anthropic Console/API cobra uso de API. Claude Code puede usar una suscripcion valida sin configurar una API aparte. Codex puede autenticarse con un plan compatible de ChatGPT o con creditos/API, modalidades que deben registrarse por separado.

Multiples agentes consumen concurrentemente. Configura limites por equipo o agente, alertas y topes de tokens/costo cuando el proveedor entregue telemetria. Si no existe un dato verificable, Crewly muestra **No disponible**, nunca cero.

Empieza con dos agentes concurrentes: uno de implementacion y uno de revision. Mide durante una semana tareas, duracion, tokens, reintentos y costo registrado antes de ampliar. Revisa la pagina oficial enlazada desde **Configuracion > Proveedores y costos**; impuestos, moneda y precios regionales pueden variar.

No hay importes de suscripcion codificados en la logica de ejecucion. La fecha del catalogo indica frescura, no garantiza la tarifa vigente.

# Terminales en vivo
## Que es
La vista de procesos PTY reales.
## Para que sirve
Comprueba comando, salida y progreso de cada runtime.
## Requisitos
Agente iniciado con HOME, PATH y permisos correctos.
## Como abrirlo
Abre el miembro activo y su terminal.
## Configuracion paso a paso
Inicia agente, observa comando, filtra logs y detiene de forma limpia.
## Ejemplo practico
Confirma `claude` para QA y `codex` para Developer.
## Como comprobar que funciona
La salida visible corresponde a la tarea real.
## Errores frecuentes
Ejecutable encontrado en shell pero ausente en systemd.
## Limites y riesgos
La salida cruda no se traduce y puede contener datos sensibles.
## Acciones relacionadas
Agentes, Logs, Salud y Proveedores.

# Cloud relay y movil
## Que es
Acceso opcional remoto y movil.
## Para que sirve
Conecta clientes fuera del dashboard local.
## Requisitos
Cuenta, red y autorizacion explicita.
## Como abrirlo
Selecciona **Nube** o el codigo movil.
## Configuracion paso a paso
Configura relay, autentica, limita alcance y prueba conexion.
## Ejemplo practico
Consulta estado desde movil sin publicar el backend directamente.
## Como comprobar que funciona
La sesion autenticada recibe solo recursos autorizados.
## Errores frecuentes
Confundir acceso local con despliegue seguro.
## Limites y riesgos
No despliegues ni expongas puertos sin autorizacion.
## Acciones relacionadas
Seguridad, Salud, Movil y Configuracion.
